# OME transcript question inventory

The inventory was generated by scanning every non-empty row in
`public.recruiter_voice_transcript` (1,465 rows). Extraction is intentionally
broader than the eventual ingestion filter: it captures explicit `?` lines and
question-shaped utterances, then labels agent script and embedded Front/SMS
history separately from carrier turns.

The durable taxonomy is in [`config/ome_question_taxonomy.yaml`](../config/ome_question_taxonomy.yaml).
It records observed intents, anonymized examples, and current evidence coverage.

## Coverage rules

- `covered_with_live_context`: the answer can be grounded in a live Carrier Hub
  response, subject to authentication and application scope.
- `partial`: examples or policy fragments exist in Front/other sources, but the
  source is not yet normalized into a reviewed canonical document.
- `gap`: transcripts show the question, but no canonical answer source has been
  approved yet. The agent must abstain until one is provided.

OME transcripts are treated as question-discovery and evaluation data, not as
policy. Agent-script and embedded-context records must not be promoted into
canonical answers without an authoritative source.
